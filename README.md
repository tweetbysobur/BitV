# BitV

**The Trust Layer for DeFi.**

Identity-native DeFi on Monad Testnet, built on Cleanverse identity and
verified-asset infrastructure. Built by Gentlesoul Hub.

This repository is at the **project foundation** stage — see
[`docs/development-log.md`](docs/development-log.md) for what exists and
[`docs/architecture.md`](docs/architecture.md) for how it's laid out.

## Getting started

```bash
cp .env.example .env.local   # fill in the values you have
npm install
npm run dev
```

## Status

Foundation only: project structure, configuration, design tokens, Web3/Monad
config, and integration boundaries. No lending, borrowing, pools, vaults,
BitScore, or live Cleanverse/contract integration yet.
